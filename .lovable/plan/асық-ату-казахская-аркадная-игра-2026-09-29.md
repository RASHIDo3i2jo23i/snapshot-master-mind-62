# Асық ату — казахская аркадная игра

Веб-игра на HTML5 Canvas в React: игрок броском сақа выбивает асыки из круга. Бирюзово-золотая гамма, казахские орнаменты, три языка, эффекты и звук.

## Экраны

1. **Меню** — название, выбор сақа (обычный / қорғасын — тяжёлый), кнопка «Ойнау», кнопка «О традиции» (модальное окно с историей игры), переключатель языка (Қазақша / Русский / English), лучший рекорд.
2. **Игра** — поле, счёт, оставшиеся броски, кнопка паузы/выхода.
3. **Результат** — победа/поражение, счёт, новый рекорд, кнопка «Сыграть снова» / «Қайта ойнау».

## Игровое поле

- Крупный круг (земля/трава) с орнаментальной каймой, фон с казахским узором.
- 5 асыков внутри круга, расставлены не слишком близко к центру, чтобы попадать было непросто:
  - 3 обычных (бежевые) — +100 очков
  - 1 золотой — +300 очков и +1 бросок
  - 1 обычный (пятый) — +100 очков
- Сақа снизу экрана, 5 бросков.

## Механика броска (навесной, с высотой)

- Оттягивание мышью/пальцем (рогатка): чем дальше, тем сильнее.
- При прицеливании — пунктирная парабола и отметка точки приземления.
- Сақа летит по дуге: пока он в воздухе, он пролетает НАД асыками и не задевает их.
- Перелёт/недолёт реальны: слабый бросок не долетает, сильный улетает за асыки.
- Столкновение только на малой высоте / при приземлении.
- Приземление: 1–2 отскока, затем качение с трением до остановки.
- Под сақа всегда рисуется тень на земле; масштаб сақа растёт на пике дуги и уменьшается при снижении.
- Тяжёлый қорғасын сақа: сильнее толкает асыки, но летит короче.

## Очки и правила

- Асык засчитывается, когда он полностью вылетает за черту круга.
- Счёт: +100 обычный, +300 золотой (+1 бросок).
- Победа — все асыки выбиты за отведённые броски, иначе поражение.
- Лучший результат хранится в браузере (localStorage).

## Эффекты («game juice»)

- Тряска экрана ~0.2 с при сильном ударе.
- Частицы: пыль при приземлении, золотые искры при вылете асыка за круг.
- Slow-mo за 0.2 с до сильного удара, затем возврат к норме.
- Всплывающие надписи при удачном броске: «Жарайсың!», «Керемет!», «Шебер!» (казахские; русское «Метко!» не используем).
- Звук через Web Audio API (синтез): свист полёта, глухой стук костей, звон при вылете асыка. Кнопка вкл/выкл звука.

## Локализация

Полный перевод интерфейса и правил на три языка, переключатель в верхнем углу, выбор запоминается.

## Техническая часть

- Одна страница `/` (index route) с игрой; canvas-компонент + React-оверлей для меню, HUD и модальных окон.
- Игровой цикл на `requestAnimationFrame` с delta-time; вся физика (x, y, z-высота, гравитация, отскок, трение, столкновения кругами) в отдельном модуле состояния, без перерисовки React каждый кадр.
- Canvas монтируется только на клиенте; рендер и ввод (mouse + touch) через ref, без обращений к `window` на этапе рендера.
- Графика рисуется процедурно на canvas (орнаменты, круг, асыки) — без внешних ассетов; фон-паттерн генерируется в коде.
- Звук — Web Audio API, контекст создаётся после первого действия игрока.
- Тексты трёх языков в одном словаре-модуле; рекорд и язык — в localStorage, чтение в эффекте после загрузки.
- Заголовок и описание страницы под игру Асық ату.
